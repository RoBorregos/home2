# ask_and_confirm confidence policy (#1384)

**Status:** implementation and pipeline done. **Real-data results pending** (week-2 recordings). The full
write-up is `research/confidence_calibration/paper/main.tex`, and every number in it is regenerated by
`python research/confidence_calibration/run_all.py --data research/confidence_calibration/data`.

## What changed on the robot
- `task_manager/utils/confidence_policy.py` (ROS-free): features, `legacy` / `binary` / `three_way` decision,
  JSONL decision log.
- `ask_and_confirm` logs one record per attempt to `logs/hri_decisions/<task>_<date>.jsonl`.
- **Normalization bug fixed:** a value normalized by the LLM ("coke" → "Coca-Cola") used to get confidence 0
  and was always confirmed. It now falls back to the closest fuzzy span, then to the whole transcription.
  The old matching can be restored with `CONFIDENCE_FIX_MATCHING = False`.
- `three_way` adds "Sorry, I couldn't hear you, could you repeat?" for low $\hat p$. This is free under the
  HRIC rules, and the robot listens again without re-asking the question.
- STT returns `avg_logprob` and `no_speech_prob` (`SpeechStream.action`, `speech.proto`).

## Flags (`frida_constants/hri_constants.py`)
| Constant | Default | Meaning |
|---|---|---|
| `CONFIDENCE_POLICY` | `"legacy"` | `legacy` = 0.7/0.7 rule, `binary`, `three_way` (need a model) |
| `CONFIDENCE_FIX_MATCHING` | `True` | normalization-bug fix for the legacy rule |
| `CONFIDENCE_LOG_ENABLED` | `True` | write the decision log |
| `CONFIDENCE_MODEL_PATH` | `confidence_model.json` | in `frida_constants/data/`, exported by `analyze.py` |
| `CONFIDENCE_THRESHOLDS` | per task | $\tau_{accept}$, $\tau_{repeat}$ from `policy_search.py` |

Without a model file, `binary` and `three_way` fall back to `legacy` and print a warning.

### TTS proxy (`make_tts_dataset.py`, then `run_all.py --data data/tts`)
The proxy has 771 attempts from 41 edge-tts voices (16 English accents) with noise, reverb and distance. Each
attempt went through **real `distil-large-v3`** with the robot settings, and the extraction LLM was emulated by
rules. Held-out set: 12 voices, 246 attempts.

| | AUROC [95% CI] | ECE | Confirm / guest | Repeat / guest | Wrong values | No value | Points / guest |
|---|---|---|---|---|---|---|---|
| (a) always confirm | | | 4.18 | 0 | 0.0% | 11.9% | -9.5 |
| (b) current heuristic 0.7/0.7 | 0.68 [0.60, 0.75] | 0.295 | 1.26 | 0 | 28.5% | 0.8% | -5.8 |
| (c) calibrated binary | | | 1.89 | 0 | 17.9% | 8.5% | -3.2 |
| (d) calibrated three-way | 0.83 [0.74, 0.92] | 0.090 | 0.27 | 2.10 | 21.8% | 11.6% | -0.7 |

- **H1 (AUROC ≥ 0.80):** supported.
- **H2 (ECE ≤ 0.05):** not supported.
- **H3:** supported, with −78.5% confirmations and −6.8 pp wrong values.

The thresholds are τ_a = 0.52 and τ_r = 0.50, so in practice the policy accepts or asks to repeat and almost
never confirms. These are proxy numbers: the error rate (48%) is much higher than expected with people, so
they show the direction of the effect with the real STT model, not its size.

`run_all.py --synthetic` only checks that the pipeline runs. Its numbers are not results.
