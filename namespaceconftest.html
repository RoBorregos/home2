Detailed Description

Test bootstrap.

A sibling ROS package is stubbed only when it is not built, so a full
workspace tests against the real one. Only packages carrying no logic under
test are eligible: the pipelines, strategies, profiles and RobotArm/Perception
are always the real thing.

def conftest._no_real_sleeping (   monkeypatch)
protected 
Unit tests must not spend real time in settle delays.

The pipelines sleep for gripper settles, mode switches and pour draining --
seconds each, minutes across the suite. None of it affects the logic under
test, which drives fakes rather than hardware.
