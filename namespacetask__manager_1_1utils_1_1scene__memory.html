The LLM's JSON split of `text`; the whole text as the target when the reply is unusable.

`snap(name, choices)` maps a name the LLM made up to the closest real one ("" if
none is close): the room must be a real room, and a furniture anchor becomes the
real piece of furniture (an object anchor, e.g. "cup", is kept as said).

Initial value:
1= """Split a household robot command into the object it asks for and where to look.
2Every value must be in English: translate the command first if it is in another language.
3- target: the object wanted, with its attributes. Empty if it is only described by its location.
4- anchor: the object or piece of furniture it is located relative to. Never a room. Empty if none.
5 Furniture in this house: {furniture}. Use those exact names for furniture.
6- room: one of {rooms} when the command names a room, otherwise empty.
7
8"bring me the red drink in the kitchen" -> target "red drink", anchor "", room "kitchen"
9"lo que está al lado de la cama" -> target "", anchor "bed", room ""
10"dame la taza que está sobre la mesa de la sala" -> target "cup", anchor "table", room "living_room"
11
12Command: {text}
13
14Answer with only one JSON object with exactly these keys, filled in, and nothing else.
15Example: {{"target": "", "anchor": "", "room": ""}}"""
